Ideal Version

  1. This book is worth reading not only for children but also for adults.
  2. If we had left earlier, we would have caught the last train.

Focus

  • be worth -ing: 「〜する価値がある」。worth の後ろは動名詞(-ing)。主語が「読まれる」側でも受動にせず The book is worth reading(× to read / × being read)とするのが定型。
  • 仮定法過去完了 If + 主語 + had + 過去分詞, 主語 + would/could have + 過去分詞: 過去の事実に反する仮定。「(実際は遅れたが)もっと早く出ていたら間に合っただろうに」。if 節は had left、主節は would have caught と、時制の組み合わせをセットで覚える。
