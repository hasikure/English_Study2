文法ポイント

1. -(으)ㄹ 수 있다 / 없다(可能・不可能)

  • 意味: 「〜できる / 〜できない」。
  • 接続: 語幹がパッチムなし → -ㄹ 수 있다、パッチムあり → -을 수 있다。否定は 있다 を 없다 に変える。
  • 例文: 보다 → 볼 수 있어요(見られます) / 읽다 → 읽을 수 있어요(読めます) / 가다 → 갈 수 없어요(行けません)。
  • 注意: 能力がなくて「できない」は 못(못 해요)も使う。状況的にできる/できないは -(으)ㄹ 수 있다/없다 が自然。

2. -(으)세요(ていねいな依頼・指示)

  • 意味: 「〜してください」。やわらかい命令・お願い。
  • 接続: 語幹がパッチムなし → -세요、パッチムあり → -으세요。
  • 例文: 말하다 → 말하세요(話してください) / 읽다 → 읽으세요(読んでください) / 앉다 → 앉으세요(座ってください)。
  • 注意: 不規則な敬語形がある。먹다/마시다 → 드세요(召し上がってください)、자다 → 주무세요(お休みください)。

3. -지 마세요(禁止)

  • 意味: 「〜しないでください」。
  • 接続: 動詞の語幹 + 지 마세요。
  • 例文: 쓰다 → 쓰지 마세요(使わないでください) / 가다 → 가지 마세요(行かないでください)。
  • 注意: タメ口の「-지 마」(〜するな)より、お願いには必ず -지 마세요 を使う。-(으)세요 の否定形にあたる。

4. 「〜と」を表す 와/과・하고・(이)랑

  • 意味: 名詞をつなぐ「〜と」。
  • 接続: 와(パッチムなし)/ 과(パッチムあり)は書き言葉的。하고・(이)랑 は話し言葉的でどちらにも付く。
  • 例文: 친구하고 가요(友だちと行きます) / 우유와 빵(牛乳とパン) / 동생이랑 놀아요(弟と遊びます)。
  • 注意: 「〜と一緒に」は 와/과/하고 + 같이 の形にする(例: 친구하고 같이).
