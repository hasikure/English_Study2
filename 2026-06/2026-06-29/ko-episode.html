오늘은 비가 와요. 그래서 저는 집에 있어요.

지금 저는 한국어를 공부하고 있어요. 음악도 듣고 있어요.

저는 비 오는 날을 좋아해요. 조용하고 편해요.

日本語訳

今日は雨が降っています。だから私は家にいます。

今、私は韓国語を勉強しています。音楽も聞いています。

雨がやんだら散歩をしたいです。でも今は本だけ読みます。

私は雨の降る日が好きです。静かで楽です。

文法ポイント

1. 現在形 -아요/어요(해요体)

  • 意味: 「〜します / 〜です」。現在の動作や状態をていねいに言う。
  • 接続: 語幹末の母音が陽母音(ㅏ, ㅗ)→ -아요、それ以外 → -어요、하다 → 해요。母音が重なると縮約する。
  • 例文: 오다 → 와요(来ます/降ります) / 읽다 → 읽어요(読みます) / 좋다 → 좋아요(良いです) / 공부하다 → 공부해요(勉強します)。
  • 注意: 過去は -았/었어요。오아요 → 와요、마시어요 → 마셔요 のように縮む形に慣れること。

2. -고 있다(現在進行)

  • 意味: 「〜している」。今まさに進行中の動作。
  • 接続: 動詞の語幹 + 고 있다(ていねい形は 고 있어요)。
  • 例文: 공부하다 → 공부하고 있어요(勉強しています) / 듣다 → 듣고 있어요(聞いています)。
  • 注意: 살다(住む)などでは継続の状態も表す。否定は 안 …고 있어요 か …고 있지 않아요。

3. -(으)면(条件・仮定)

  • 意味: 「〜たら / 〜なら / 〜と」。条件をつくる。
  • 接続: 語幹がパッチムなし → -면、パッチムあり → -으면。
  • 例文: 그치다 → 그치면(やんだら) / 시간이 있다 → 있으면(あれば)。
  • 注意: 「〜するとき」を表す -(으)ㄹ 때 とは別。条件は -(으)면、時点は -(으)ㄹ 때 と使い分ける。

4. 助詞 도(〜も)と 만(〜だけ)

  • 意味: 도 は「〜も」(追加)、만 は「〜だけ」(限定)。
  • 接続: 名詞に直接付く。을/를・이/가 は普通 도・만 に置き換わる。
  • 例文: 음악도 들어요(音楽も聞きます) / 책만 읽어요(本だけ読みます)。
  • 注意: 「〜にも」は 에도、「〜でも(場所)」は 에서도 のように、場所の助詞の後ろに 도 を付ける。
