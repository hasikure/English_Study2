내일은 일요일이에요. 저는 시장에 과일을 사러 갈 거예요.

시장에서 사과하고 딸기를 살 거예요. 그런데 고기는 안 살 거예요.

저는 요리를 좋아해서 주말에 자주 만들어요.

오후에는 친구도 우리 집에 올 거예요. 우리는 같이 저녁을 먹을 거예요.

日本語訳

明日は日曜日です。私は市場に果物を買いに行くつもりです。

市場でりんごといちごを買うつもりです。でも、肉は買いません。

私は料理が好きなので、週末によく作ります。

午後には友だちもうちに来るつもりです。私たちは一緒に夕食を食べるつもりです。

文法ポイント

1. -(으)ㄹ 거예요(未来・意志)

  • 意味: 「〜するつもりです / 〜でしょう」。これからの予定や意志を表す。
  • 接続: 語幹がパッチムなし → -ㄹ 거예요、パッチムあり → -을 거예요。
  • 例文: 가다 → 갈 거예요(行くつもりです) / 먹다 → 먹을 거예요(食べるつもりです) / 사다 → 살 거예요(買うつもりです)。
  • 注意: 話し言葉では 거예요 を「꺼예요」のように発音する。過去の「-았/었어요」と対にして覚えるとよい。

2. -(으)러 가다/오다(移動の目的)

  • 意味: 「〜しに行く / 〜しに来る」。移動の目的を表す。
  • 接続: 語幹がパッチムなし → -러、パッチムあり → -으러。後ろは가다・오다・다니다など移動動詞。
  • 例文: 사다 → 사러 가요(買いに行きます) / 먹다 → 먹으러 와요(食べに来ます)。
  • 注意: 似た形の -(으)려고(〜しようと)は後ろに移動動詞以外も来る。混同しないこと。

3. 否定の 안 と -지 않다

  • 意味: 「〜しない / 〜くない」。안 と -지 않다 はほぼ同じ意味。
  • 接続: 안 は動詞・形容詞の前に置く。-지 않다 は語幹の後ろに付ける。
  • 例文: 안 사요 = 사지 않아요(買いません) / 안 비싸요 = 비싸지 않아요(高くないです)。
  • 注意: 「名詞+하다」の動詞は 하다 の前に 안 を入れる。공부 안 해요(○) / 안 공부해요(×)。

4. 助詞 에서 と 에

  • 意味: 에서 は「〜で」(動作が行われる場所)、에 は「〜に / 〜へ」(行き先や存在する場所)。
  • 例文: 시장에서 과일을 사요(市場で果物を買います) / 시장에 가요(市場に行きます)。
  • 注意: 가다・오다 など移動の到達点には 에、먹다・사다・만들다 など動作の場所には 에서 を使う。
