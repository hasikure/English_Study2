文法ポイント

1. -기 전에(「〜する前に」)

  • 意味: 「〜する前に」。
  • 接続: 動詞の語幹 + 기 전에。名詞は「名詞 + 전에」。
  • 例文: 먹다 → 먹기 전에(食べる前に) / 자다 → 자기 전에(寝る前に) / 식사 전에(食事の前に)。
  • 注意: 全体の時制は最後の動詞で示す(過去でも 먹기 전에 のまま、文末で 씻었어요 のように過去にする)。

2. -(으)ㄴ 후에 / -(으)ㄴ 다음에(「〜した後に」)

  • 意味: 「〜した後に」。
  • 接続: 動詞の語幹がパッチムなし → -ㄴ 후에、パッチムあり → -은 후에。후에 の代わりに 다음에 / 뒤에 も同義。名詞は「名詞 + 후에」。
  • 例文: 일어나다 → 일어난 후에(起きた後に) / 먹다 → 먹은 후에 / 수업 후에(授業の後に)。
  • 注意: -고 나서(〜してから)ともほぼ同じ意味。

3. -(으)면서(「〜しながら」同時動作)

  • 意味: 二つの動作を同時にする「〜しながら」。主語は同じ。
  • 接続: 語幹がパッチムなし → -면서、パッチムあり → -으면서。
  • 例文: 듣다 → 들으면서(聞きながら) / 걷다 → 걸으면서(歩きながら) / 먹다 → 먹으면서。
  • 注意: 걷다・듣다 は ㄷ不規則で 걸-/들- に変わる(걸어서=歩いて、들어요=聞きます)。この不規則は 면서 でも起こる。

4. -네요(「〜ですね」感嘆)

  • 意味: 見たり聞いたりして感じたことへの軽い感嘆「〜ですね / 〜ますね」。
  • 接続: 動詞・形容詞の語幹 + 네요(パッチムの有無を問わない)。
  • 例文: 좋다 → 좋네요(いいですね) / 많다 → 많네요(多いですね) / 하다 → 하네요。
  • 注意: 過去は -았/었네요(좋았네요 = 良かったですね)。相手に確認を求める -지요? とはニュアンスが違う。
