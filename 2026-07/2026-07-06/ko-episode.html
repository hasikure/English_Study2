이번 주말에 비가 올 것 같아요.

저는 비 오는 날을 좋아하는데, 밖에 나가기는 싫어요.

그래서 아침부터 저녁까지 집에서 책을 읽으려고 해요.

재미있는 책이 많아서 심심하지 않을 것 같아요.

日本語訳

今週末は雨が降りそうです。

私は雨の降る日が好きですが、外に出るのは嫌です。

だから朝から夕方まで、家で本を読もうと思います。

面白い本がたくさんあるので、退屈しなさそうです。

文法ポイント

1. -(으)ㄹ 것 같다(推量「〜しそう / 〜だと思う」)

  • 意味: 根拠のある推量「〜しそうだ / 〜だと思う」。
  • 接続: 語幹がパッチムなし → -ㄹ 것 같다、パッチムあり → -을 것 같다。名詞は「名詞 + 일 것 같다」。
  • 例文: 오다 → 올 것 같아요(降りそうです) / 좋다 → 좋을 것 같아요 / 없다 → 없을 것 같아요。
  • 注意: 過去の推量は -(으)ㄴ 것 같다(비가 온 것 같아요 = 降ったようだ)、現在進行の推量は -는 것 같다。

2. 連体形(動詞 -는 / 形容詞 -(으)ㄴ)+ 名詞

  • 意味: 名詞を修飾する「〜する〜 / 〜な〜」。
  • 接続: 現在、動詞は語幹 + 는(먹는 사람 = 食べる人)。形容詞はパッチムなし + ㄴ / あり + 은(예쁜 꽃 = きれいな花、좋은 책 = 良い本)。
  • 例文: 오다 → 오는 날(降る日) / 재미있다 → 재미있는 책(面白い本) / 조용하다 → 조용한 음악。
  • 注意: 動詞の過去連体形は -(으)ㄴ(먹은 = 食べた〜)、未来連体形は -(으)ㄹ。

3. -는데 / -(으)ㄴ데(前置き・背景「〜だが / 〜なので」)

  • 意味: 前置き・背景・軽い逆接「〜だが、〜のに、〜なので」。
  • 接続: 動詞・있다/없다は語幹 + 는데、形容詞はパッチムなし + ㄴ데 / あり + 은데。
  • 例文: 좋아하다 → 좋아하는데(好きだけど) / 좋다 → 좋은데(いいけど) / 있다 → 있는데。
  • 注意: 文脈により逆接にも、理由・状況説明にもなる万能表現。会話でとても多い。

4. 「〜から〜まで」: 부터 … 까지 / 에서 … 까지

  • 意味: 時間は 부터 … 까지(〜から〜まで)、場所は 에서 … 까지。
  • 接続: 名詞に直接付く。到達点はどちらも 까지。
  • 例文: 아침부터 저녁까지(朝から夕方まで) / 집에서 학교까지(家から学校まで)。
  • 注意: 起点が時間なら 부터、場所なら 에서 を使い分ける。
