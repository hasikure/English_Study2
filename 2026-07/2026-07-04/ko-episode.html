文法ポイント

1. -(으)ㄹ게요(意志・約束「〜しますね」)

  • 意味: 話し手の意志・約束「(私が)〜しますね」。相手を意識した言い方。
  • 接続: 語幹がパッチムなし → -ㄹ게요、パッチムあり → -을게요。主語は基本1人称(私)。
  • 例文: 예매하다 → 예매할게요(予約しますね) / 가다 → 갈게요 / 먹다 → 먹을게요。
  • 注意: 発音は「께요」。相手の意向を尋ねる -(으)ㄹ래요? と対で使うと自然。

2. -(으)ㄹ래요? / -(으)ㄹ래요(意向・勧誘「〜する?/〜します」)

  • 意味: 疑問文で相手の意向を尋ねる「〜する?」、平叙文で自分の希望「〜します」。くだけた提案。
  • 接続: 語幹がパッチムなし → -ㄹ래요、パッチムあり → -을래요。
  • 例文: 보다 → 볼래요?(見る?) / 먹다 → 먹을래요(食べます)。
  • 注意: より丁寧に誘うときは -(으)시겠어요? を使う。

3. -지요? / -죠?(確認「〜でしょう?」)

  • 意味: 相手も知っている・同意するだろうことを確認する「〜でしょう?/〜ですよね?」。
  • 接続: 語幹 + 지요(縮約して 죠)。
  • 例文: 재미있다 → 재미있죠?(面白いでしょう?) / 맞다 → 맞죠?(合ってますよね?)。
  • 注意: 平叙で使うと「〜ですよ(ね)」の柔らかい断定。過去は -았/었죠?。

4. 밖에 + 否定(「〜しか(〜ない)」)

  • 意味: 「〜しか(…ない)」。必ず後ろに否定表現が来る。
  • 接続: 名詞 + 밖에。
  • 例文: 저녁밖에 없어요(夕方しかありません) / 물밖에 안 마셔요(水しか飲みません)。
  • 注意: 만(〜だけ)は肯定文でも使えるが、밖에 は否定とセットでのみ使う。
