겨울에는 눈이 와요. 눈이 솜사탕처럼 하얘요.

저는 건강해지기 위해서 겨울에도 매일 운동해요.

운동하는 동안 좋아하는 음악을 들어요.

日本語訳

私は夏より冬の方が好きです。

冬には雪が降ります。雪は綿あめのように白いです。

私は健康になるために、冬でも毎日運動します。

運動している間、好きな音楽を聞きます。

文法ポイント

1. -기 위해서(目的「〜するために」)

  • 意味: 「〜するために」。目的を表す。
  • 接続: 動詞の語幹 + 기 위해서(위해 でも可)。名詞は「名詞 + 을/를 위해서」。
  • 例文: 건강해지다 → 건강해지기 위해서(健康になるために) / 배우다 → 배우기 위해서 / 가족을 위해서(家族のために)。
  • 注意: 話し言葉の -(으)려고(〜しようと)より、ややかたい・文章的な言い方。

2. 보다 (더)(比較「〜より(もっと)」)

  • 意味: 二つを比べて「〜より(もっと)」。
  • 接続: 比べる対象の名詞 + 보다。더(もっと)を添えることが多い。
  • 例文: 여름보다 겨울을 더 좋아해요(夏より冬の方が好き) / 동생보다 키가 커요(弟より背が高い)。
  • 注意: 「〜が一番」は 제일 / 가장 を使う(제일 좋아해요 = 一番好き)。

3. 처럼 / 같이(「〜のように」)

  • 意味: たとえ・比喩「〜のように、〜みたいに」。
  • 接続: 名詞 + 처럼 / 名詞 + 같이。
  • 例文: 눈처럼 하얘요(雪のように白い) / 가수같이 노래해요(歌手のように歌う)。
  • 注意: 같이 には「一緒に」の意味もある(친구하고 같이 = 友だちと一緒に)。文脈で区別する。

4. -는 동안(에)(「〜する間(に)」)

  • 意味: ある動作が続く時間「〜する間(に)」。
  • 接続: 動詞の語幹 + 는 동안(에)。名詞は「名詞 + 동안」。
  • 例文: 운동하는 동안(運動している間) / 자는 동안에(寝ている間に) / 방학 동안(休みの間)。
  • 注意: 期間の長さも 名詞+동안 で表す(삼 년 동안 = 3年間)。
