아침에 일어나자마자 시계를 봤어요. 벌써 여덟 시였어요.

朝起きるとすぐに時計を見ました。もう8時でした。

もう少し早く起きればよかったです。

文法ポイント

1. -자마자(「〜するとすぐに」)

  • 意味: ある動作の直後に、別のことが起こることを表す。
  • 接続: 動詞の語幹 + 자마자(時制に関係なく語幹にそのまま付ける)。
  • 例文: 일어나다 → 일어나자마자(起きるとすぐに) / 도착하다 → 도착하자마자(着くとすぐに)。
  • 注意: -고 나서(〜してから)より「間を置かず、すぐに」という即時性が強い。

2. -느라고(「〜していたせいで」原因・理由)

  • 意味: ある動作をしていたために、望ましくない結果になったことを表す。
  • 接続: 動詞の語幹 + 느라고。
  • 例文: 자다 → 늦잠을 자느라고(寝坊していたせいで) / 보다 → 텔레비전을 보느라고(テレビを見ていたせいで)。
  • 注意: 後ろにはたいてい「〜できなかった、〜し損ねた」など望ましくない結果が続く。

3. -(으)ㄹ 걸 그랬다(「〜すればよかった」後悔)

  • 意味: 過去にしなかったこと・したことへの後悔を表す。
  • 接続: 動詞の語幹がパッチムなし → -ㄹ 걸 그랬다、パッチムあり → -을 걸 그랬다。
  • 例文: 일어나다 → 일찍 일어날 걸 그랬어요(早く起きればよかった) / 가다 → 갈 걸 그랬어요(行けばよかった)。
  • 注意: 「〜しなければよかった」という否定の後悔は -지 말 걸 그랬다 の形になる。

4. 만큼(「〜ほど、〜くらい」比較・程度)

  • 意味: 二つを比べて、同じくらいの程度であることを表す。
  • 接続: 名詞 + 만큼、または動詞・形容詞の連体形 + 만큼。
  • 例文: 생각하다 → 생각한 만큼(思ったほど) / 형만큼 커요(兄と同じくらい背が高い)。
  • 注意: 否定文と一緒に使うと「思ったほど〜ではない」という控えめな表現になる(생각한 만큼 피곤하지 않아요=思ったほど疲れていない)。
