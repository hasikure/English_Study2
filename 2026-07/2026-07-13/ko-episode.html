한국어를 잘하고 싶으면 매일 공부하는 게 좋아요.

저는 바쁜데도 날마다 삼십 분씩 공부해요.

그리고 주말마다 한국 드라마도 봐요.

힘들 때는 커피나 차를 마시면서 쉬어요.

日本語訳

韓国語が上手になりたいなら、毎日勉強した方がいいです。

私は忙しいのに、毎日30分ずつ勉強します。

そして週末ごとに、韓国ドラマも見ます。

つらいときは、コーヒーかお茶を飲みながら休みます。

文法ポイント

1. -는 게 좋겠어요 / -는 게 좋아요(助言「〜した方がいい」)

  • 意味: 「〜した方がいい / 〜するのがいい」。助言・提案。
  • 接続: 動詞の語幹 + 는 게 좋다(게 = 것이 の縮約)。
  • 例文: 공부하다 → 공부하는 게 좋아요(勉強した方がいい) / 쉬다 → 쉬는 게 좋겠어요。
  • 注意: 좋겠어요 の方が、ややひかえめで丁寧な助言になる。

2. -(으)ㄴ/는데도(逆接「〜のに、〜にもかかわらず」)

  • 意味: 「〜のに、〜にもかかわらず」。予想に反することを言う。
  • 接続: 動詞・있다/없다は語幹 + 는데도、形容詞はパッチムなし + ㄴ데도 / あり + 은데도。
  • 例文: 바쁘다 → 바쁜데도(忙しいのに) / 공부하다 → 공부하는데도。
  • 注意: 前置きの -는데 に 도(も)が付いた形。「それでも」を強める。

3. -마다(「〜ごとに、〜たびに」)

  • 意味: 「〜ごとに、〜たびに」。反復を表す。
  • 接続: 名詞 + 마다。
  • 例文: 날마다(毎日=日ごとに) / 주말마다(週末ごとに) / 사람마다(人それぞれ)。
  • 注意: 「〜するたびに」は -(으)ㄹ 때마다(볼 때마다 = 見るたびに)。

4. -(이)나(選択・数量の強調「〜でも / 〜も」)

  • 意味: ① 選択「AかB(でも)」 ② 数量が多いことへの驚き「〜も」。
  • 接続: 名詞がパッチムなし → -나、パッチムあり → -이나。
  • 例文: 커피나 차(コーヒーかお茶) / 세 시간이나(3時間も)。
  • 注意: 「〜か」(選択)と「〜も」(数量の多さ)の二つの用法があり、文脈で判断する。
