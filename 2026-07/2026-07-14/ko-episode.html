文法ポイント

1. -는 것 같다(動詞の現在推量:今〜しているようだ)

  • 意味: 目の前の様子から「今〜しているようだ」と推測する。
  • 接続: 動詞の語幹 + 는 것 같다。
  • 例文: 오다 → 비가 오는 것 같아요(雨が降っているようです) / 자다 → 아기가 자는 것 같아요(赤ちゃんが寝ているようです)。
  • 注意: 未来の推量 -(으)ㄹ 것 같다(〜しそう、7/10で学習)とは時点が違う。今まさに起きていることの推測。

2. -(으)ㄴ 것 같다(形容詞は「今」、動詞は「過去」)

  • 意味: 形容詞に付くと「〜なようだ」(現在の状態)、動詞に付くと「〜したようだ」(すでに終わったこと)。
  • 接続: 形容詞パッチムなし → -ㄴ 것 같다 / あり → -은 것 같다。動詞も同じ形だが意味は過去になる。
  • 例文: 흐리다 → 흐린 것 같아요(曇っているようです=形容詞・今の状態) / 오다 → 비가 온 것 같아요(雨が降ったようです=動詞・過去)。
  • 注意: 同じ形でも品詞によって「今」か「過去」かが変わる。動詞か形容詞かをまず確認すること。

3. -아/어 보이다(見た目の印象:〜に見える)

  • 意味: 見た目・印象から「〜に見える」。
  • 接続: 形容詞の語幹 + 아/어 보이다(하다 → 해 보이다)。
  • 例文: 피곤하다 → 피곤해 보여요(疲れて見えます) / 좋다 → 좋아 보여요(良さそうに見えます)。
  • 注意: -는 것 같다(推測全般)より、視覚的な印象に限定した表現。

4. -기도 하다(「〜することもある/〜もする」)

  • 意味: 他にもある事実や、時々あることを付け加える。
  • 接続: 動詞・形容詞の語幹 + 기도 하다。
  • 例文: 좋다 → 좋기도 해요(いいこともあります) / 가다 → 가기도 해요(行くこともあります)。
  • 注意: 複数の事実を並べるときは「-기도 하고 …기도 해요」の形でつなげられる。
