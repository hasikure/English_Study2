저는 오늘 몸이 안 좋아요. 그래서 회사에 못 갔어요.

아플 때는 푹 쉬어야 돼요. 약도 먹어야 돼요.

회사에 전화했어요. 부장님이 "오늘은 집에서 쉬어도 돼요"라고 했어요.

내일은 중요한 회의가 있으니까 꼭 가야 돼요.

日本語訳

私は今日、体の調子が良くありません。だから会社に行けませんでした。

具合が悪いときは、ぐっすり休まなければなりません。薬も飲まなければなりません。

会社に電話しました。部長が「今日は家で休んでもいいですよ」と言いました。

明日は大事な会議があるので、必ず行かなければなりません。

文法ポイント

1. -아/어야 되다 / 하다(義務「〜しなければならない」)

  • 意味: 「〜しなければならない / 〜する必要がある」。
  • 接続: 語幹 + 아/어야 되다(または 하다)。하다動詞 → 해야 돼요。
  • 例文: 쉬다 → 쉬어야 돼요(休まなければなりません) / 가다 → 가야 돼요 / 먹다 → 먹어야 돼요。
  • 注意: 되다 と 하다 はほぼ同じ意味で、話し言葉では 돼요 が多い。過去は -아/어야 됐어요(〜しなければならなかった)。

2. -아/어도 되다(許可「〜してもいい」)

  • 意味: 「〜してもいい / 〜して構わない」。
  • 接続: 語幹 + 아/어도 되다(돼요)。
  • 例文: 쉬다 → 쉬어도 돼요(休んでもいいです) / 가다 → 가도 돼요。質問は 가도 돼요?(行ってもいいですか)。
  • 注意: だめなときは 안 돼요 / -(으)면 안 돼요(〜してはいけない)で答える。

3. -(으)ㄹ 때(「〜するとき」)

  • 意味: 「〜するとき / 〜のとき」。時点を表す。
  • 接続: 語幹がパッチムなし → -ㄹ 때、パッチムあり → -을 때。名詞は「名詞 + 때」。
  • 例文: 아프다 → 아플 때(具合が悪いとき) / 먹다 → 먹을 때 / 어릴 때(幼いとき)。
  • 注意: 条件の -(으)면(〜なら)とは別。過去の一点は -았/었을 때(〜したとき)。

4. -(으)니까(理由「〜だから」)

  • 意味: 「〜だから / 〜なので」。理由を表す。
  • 接続: 語幹がパッチムなし → -니까、パッチムあり → -으니까。
  • 例文: 있다 → 있으니까(あるから) / 바쁘다 → 바쁘니까(忙しいから)。
  • 注意: 命令・勧誘の理由には -아서/어서 でなく -(으)니까 を使う(시간이 없으니까 빨리 가요 = 時間がないから早く行こう)。
