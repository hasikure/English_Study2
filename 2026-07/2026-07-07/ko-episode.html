제 이름은 유키라고 해요. 저는 일본 사람이에요.

저는 한국 요리를 아주 좋아하기 때문에 요즘 요리를 배워요.

저는 김치를 만들 줄 알아요. 하지만 아직 잘 못해요.

그래서 사 먹지 말고 집에서 직접 만들고 싶어요.

日本語訳

私の名前はユキといいます。私は日本人です。

私は韓国料理がとても好きなので、最近、料理を習っています。

私はキムチを作れます。でも、まだ上手ではありません。

だから、買って食べないで、家で自分で作りたいです。

文法ポイント

1. -(으)ㄹ 줄 알다 / 모르다(方法・能力「〜できる/やり方を知っている」)

  • 意味: 「〜する方法を知っている(=できる)/ 知らない(=できない)」。
  • 接続: 語幹がパッチムなし → -ㄹ 줄 알다、パッチムあり → -을 줄 알다。できない側は 알다 を 모르다 に。
  • 例文: 만들다 → 만들 줄 알아요(作れます) / 하다 → 할 줄 몰라요(やり方を知りません)。
  • 注意: -(으)ㄹ 수 있다(可能)は状況的な可能も含むが、-(으)ㄹ 줄 알다 は「技術・方法を身につけている」ニュアンス。

2. -기 때문에(理由「〜だから、〜のため」)

  • 意味: 「〜だから、〜のために」。理由をややかたく述べる。
  • 接続: 動詞・形容詞の語幹 + 기 때문에。名詞は「名詞 + (이)기 때문에」。
  • 例文: 좋아하다 → 좋아하기 때문에(好きだから) / 바쁘다 → 바쁘기 때문에。文末は -기 때문이에요(〜だからです)。
  • 注意: 命令・勧誘の理由には使いにくい(そこは -(으)니까 を使う)。

3. -(이)라고 하다(引用・呼称「〜という」)

  • 意味: 名前や内容を伝える「〜と言います / 〜という」。
  • 接続: 名詞がパッチムなし → -라고 하다、パッチムあり → -이라고 하다。
  • 例文: 이름이 유키라고 해요(名前はユキといいます) / 이것은 김치라고 해요(これはキムチといいます)。
  • 注意: 文の引用は -다고/냐고/자고/(으)라고 하다(間接話法)へ広がる。まずは名詞の -(이)라고 하다 から。

4. -지 말고(「〜しないで、〜せずに」)

  • 意味: 前の動作を否定して別の動作を促す「〜しないで、〜せずに(…する)」。
  • 接続: 動詞の語幹 + 지 말고。
  • 例文: 사 먹다 → 사 먹지 말고 만들어요(買って食べないで作ります) / 걱정하다 → 걱정하지 말고。
  • 注意: 「〜しないでください」の -지 마세요 と関連。-지 말고 の後ろには別の指示・勧誘が続く。
