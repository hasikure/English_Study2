文法ポイント

1. -(으)ㄹ까요?(勧誘・提案「〜しましょうか」)

  • 意味: 相手の意向を尋ねる「〜しましょうか / 〜でしょうか」。
  • 接続: 語幹がパッチムなし → -ㄹ까요?、パッチムあり → -을까요?。
  • 例文: 먹다 → 먹을까요?(食べましょうか) / 가다 → 갈까요?(行きましょうか)。答えは 네, 좋아요 や -아/어요(〜しましょう)。
  • 注意: 「雨が降るでしょうか」のような推量にも使う(비가 올까요?)。

2. -아/어 주세요(依頼「〜してください」)

  • 意味: 相手に何かを「してもらう」お願い。
  • 接続: 語幹 + 아/어 주세요(하다 → 해 주세요)。名詞なら「名詞 + 주세요」で「〜をください」。
  • 例文: 하다 → 안 맵게 해 주세요(辛くしないでください) / 쓰다 → 써 주세요(書いてください) / 물 주세요(お水をください)。
  • 注意: 単なる指示の -(으)세요(앉으세요=座ってください)より、「自分のためにしてもらう」ニュアンスが強い。

3. 못 + 動詞 / -지 못하다(能力の否定「〜できない」)

  • 意味: 能力や状況で「〜できない」。
  • 接続: 動詞の前に 못、または語幹 + 지 못하다。
  • 例文: 못 먹어요 = 먹지 못해요(食べられません) / 못 가요 = 가지 못해요(行けません)。
  • 注意: 「名詞+하다」は 못 を하다の前に。운동 못 해요(○)。意志の否定「〜しない」の 안(안 먹어요=食べない)と区別する。

4. 固有数詞 + 助数詞(개, 시, 명 …)

  • 意味: ものを数える「〜個」、時刻「〜時」、人「〜人」など。
  • 接続: 固有数詞 하나·둘·셋… は助数詞の前で 한·두·세… に変化する。
  • 例文: 두 개(2個) / 한 시(1時) / 세 명(3人)。
  • 注意: 数を数えるときは固有数詞、分・年月日・値段などは漢数詞(일·이·삼…)を使う。개 の前は 한/두/세 の形になる。
