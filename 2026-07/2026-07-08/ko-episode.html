文法ポイント

1. -고 나서(順序「〜してから」)

  • 意味: 「〜してから、〜し終えて(次に)」。動作の順序。
  • 接続: 動詞の語幹 + 고 나서。
  • 例文: 일어나다 → 일어나고 나서(起きてから) / 먹다 → 먹고 나서(食べてから)。
  • 注意: 単なる並列の -고(〜して)より「前の動作を終えてから」を強調する。-(으)ㄴ 후에(〜した後で)とほぼ同義。

2. -아/어 있다(状態の継続「〜している(状態)」)

  • 意味: 動作の結果が続いている状態「〜している / 〜してある」。
  • 接続: 自動詞の語幹 + 아/어 있다。
  • 例文: 놓이다 → 놓여 있어요(置いてあります) / 앉다 → 앉아 있어요(座っています) / 열리다 → 열려 있어요(開いています)。
  • 注意: 動作の進行を表す -고 있다(먹고 있어요 = 食べている最中)とは別。「座っている状態」は 앉아 있다。

3. -(으)ㄴ 지 (期間) 됐어요 / 지났어요(「〜してから(期間)になる」)

  • 意味: ある動作から「どれくらい経ったか」。
  • 接続: 動詞の語幹がパッチムなし → -ㄴ 지、パッチムあり → -은 지 + 期間 + 됐어요 / 지났어요。
  • 例文: 배우다 → 배운 지 육 개월 됐어요(習って6か月になりました) / 오다 → 온 지 이 년 됐어요。
  • 注意: この 지 は「〜してから」の意味。疑問の -는지(〜かどうか)とは別。

4. -(으)ㄴ/는 편이다(「どちらかというと〜な方だ」)

  • 意味: 断定を避けて「〜な方だ、比較的〜だ」。
  • 接続: 形容詞パッチなし → -ㄴ 편이다 / あり → -은 편이다、動詞の現在は -는 편이다。
  • 例文: 조용하다 → 조용한 편이에요(静かな方です) / 많이 먹다 → 많이 먹는 편이에요。
  • 注意: 「はっきりそうだ」ではなく「傾向として」を表す、やわらかい言い方。
