본문

어제 저는 길을 건너다가 하마터면 넘어질 뻔했어요.

다행히 친구가 저를 도와주고 약국에서 약을 사다 줬어요.

저는 너무 아파서 신발을 신은 채로 침대에 누웠어요.

그리고 음악을 들으면서 좀 쉬었어요.

日本語訳

昨日、私は道を渡っている途中で、もう少しで転ぶところでした。

幸い、友だちが私を助けてくれて、薬局で薬を買ってきてくれました。

私はとても痛かったので、靴を履いたままベッドに横になりました。

そして音楽を聞きながら、少し休みました。

文法ポイント

1. -(으)ㄹ 뻔하다(「もう少しで〜するところだった」)

  • 意味: 実際には起きなかったが、あと少しで起きそうだったことを表す。
  • 接続: 動詞の語幹がパッチムなし → -ㄹ 뻔하다、パッチムあり → -을 뻔하다。
  • 例文: 넘어지다 → 넘어질 뻔했어요(転ぶところでした) / 늦다 → 늦을 뻔했어요(遅れるところでした)。
  • 注意: 実際には起きなかったことなので、常に過去形 -(으)ㄹ 뻔했어요 の形で使う。

2. -아/어다 주다(「〜してきてあげる/くれる」)

  • 意味: 何かをして、それを持ってきて相手にしてあげる(買う・持ってくる、など移動を伴う動作)。
  • 接続: 動詞の語幹 + 아/어다 주다。
  • 例文: 사다 → 사다 주다(買ってきてあげる) / 가져오다 → 가져다주다(持ってきてくれる)。
  • 注意: 普通の -아/어 주다(その場でしてあげる)と違い、「どこかへ行って、それをして戻ってくる」という移動のニュアンスが入る。

3. -(으)ㄴ 채로(「〜したままの状態で」)

  • 意味: ある状態を変えないまま、別の動作をする。
  • 接続: 動詞の過去連体形(パッチムなし → -ㄴ 채로、あり → -은 채로)。
  • 例文: 신다 → 신은 채로(履いたまま) / 켜다 → 켠 채로(つけたまま)。
  • 注意: 「〜して、そのまま」の -고 と似るが、-(으)ㄴ 채로 は「本来なら変えるはずの状態を、あえて変えないまま」というニュアンスが強い。

4. -(으)면서(「〜しながら」同時動作)

  • 意味: 同じ主語が二つの動作を同時に行う。
  • 接続: 動詞の語幹がパッチムなし → -면서、パッチムあり → -으면서。
  • 例文: 가다 → 가면서(行きながら) / 먹다 → 먹으면서(食べながら) / 듣다(ㄷ不規則)→ 들으면서(聞きながら)。
  • 注意: 期間の幅を表す -는 동안(7/6で学習)とは違い、-(으)면서 は「同時に行う二つの動作」そのものを強調する。
