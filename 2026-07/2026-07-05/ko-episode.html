文法ポイント

1. -아/어 보다(試み「〜してみる」)

  • 意味: 「〜してみる」。試しにやってみる。
  • 接続: 語幹 + 아/어 보다(하다 → 해 보다)。
  • 例文: 만들다 → 만들어 봤어요(作ってみました) / 먹다 → 먹어 보다 / 가다 → 가 보다。
  • 注意: 過去 -아/어 봤다 は「〜してみた」。次の -(으)ㄴ 적이 있다(経験)と近いが、보다 は「試みる」に焦点がある。

2. -(으)ㄴ 적이 있다 / 없다(経験「〜したことがある/ない」)

  • 意味: 「〜したことがある / ない」。過去の経験の有無。
  • 接続: 動詞の語幹がパッチムなし → -ㄴ 적이 있다、パッチムあり → -은 적이 있다。
  • 例文: 가다 → 간 적이 있어요(行ったことがあります) / 먹다 → 먹은 적이 없어요(食べたことがありません)。
  • 注意: 単なる過去 -았/었어요(〜した)と違い、「経験があるかどうか」を表す。

3. -(으)려고 하다(意図「〜しようと思う」)

  • 意味: 「〜しようと思う / 〜するつもりだ」。意図・計画。
  • 接続: 語幹がパッチムなし → -려고 하다、パッチムあり → -으려고 하다。
  • 例文: 가다 → 가려고 해요(行こうと思います) / 먹다 → 먹으려고 해요。
  • 注意: 単純な予定は -(으)ㄹ 거예요、「〜しようという意図」は -(으)려고 하다。話し言葉では -려고요 で止めることもある。

4. -기로 하다(決定「〜することにする」)

  • 意味: 「〜することにする / 〜すると決める」。決心・約束。
  • 接続: 動詞の語幹 + 기로 하다。
  • 例文: 공부하다 → 공부하기로 했어요(勉強することにしました) / 만나다 → 만나기로 하다。
  • 注意: 過去 -기로 했다 で「(すでに)〜することにした」。約束にも使う(내일 만나기로 했어요 = 明日会うことにしました)。
