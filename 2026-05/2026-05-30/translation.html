Ideal Version

  1. Even if you fail, there is meaning in the fact that you tried.
  2. There used to be several bookshops on this street, but hardly any remain now.

Focus

  • even if: 「たとえ〜だとしても」。仮定の条件を表す。even though（実際にそうであっても）との違いに注意——even if は仮定、even though は事実。
  • used to do: 「以前は〜していた（今はしていない）」。過去の習慣や状態で、現在との対比を含む。There used to be ... で「以前は〜があった」。would との違い：used to は状態にも使えるが、would は動作の習慣にのみ使う（例：There would be ... は×）。
