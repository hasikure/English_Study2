文法ポイント

1. -(이)라서(「〜なので」名詞+理由)

  • 意味: 名詞を根拠にした理由を表す。
  • 接続: 名詞 + (이)라서(パッチムなし→라서、あり→이라서)。
  • 例文: 휴일이다 → 오늘은 휴일이라서 사람이 많았어요(今日は休日なので人が多かったです) / 학생이다 → 학생이라서 할인을 받았어요(学生なので割引を受けました)。
  • 注意: 動詞・形容詞に付く -아/어서 の名詞版。「휴일이어서」と言うこともできるが、話し言葉では -이라서 の方がよく使われる。

2. -(으)ㄹ 줄 몰랐다/알았다(「〜とは思わなかった,知らなかった」予想外の事実)

  • 意味: 実際にそうなる・そうであるとは予想していなかった、という驚きを表す。
  • 接続: 動詞・形容詞の未来連体形(語幹+(으)ㄹ)+ 줄 몰랐다/알았다。
  • 例文: 나쁘다 → 시력이 이렇게 나쁠 줄 몰랐어요(視力がこんなに悪いとは知りませんでした) / 오다 → 손님이 이렇게 많이 올 줄 몰랐어요(お客さんがこんなに来るとは思いませんでした)。
  • 注意: 同じ形で「〜する方法を知っている/いない」という能力の意味にもなるので(例: 수영할 줄 알아요=泳ぎ方を知っている)、文脈で判断する。

3. -네요(「〜ですね」気づき・感嘆)

  • 意味: 今まさに気づいたこと、新鮮に感じたことに対する軽い感嘆を表す。
  • 接続: 動詞・形容詞の語幹 + 네요。
  • 例文: 보이다 → 세상이 훨씬 또렷하게 보이네요(世の中がずっとはっきり見えますね) / 많다 → 사람이 정말 많네요(人が本当に多いですね)。
  • 注意: 単なる事実を述べる -아/어요 と違い、「今この瞬間に気づいた」という新鮮な感嘆のニュアンスを持つ。

4. -아/어 버리다(「〜してしまう」完了・後悔)

  • 意味: ある行動が完全に終わったことを表し、しばしば残念・後悔の気持ちを伴う。
  • 接続: 動詞の語幹 + 아/어 버리다(陽母音→아 버리다、陰母音→어 버리다)。
  • 例文: 놓다 → 예전 안경을 그냥 놓고 나와 버렸어요(古い眼鏡をそのまま置いて出てきてしまいました) / 잊다 → 약속을 잊어버렸어요(約束を忘れてしまいました)。
  • 注意: 完了を表す -아/어 놓다 と違い、-아/어 버리다 は「取り返しがつかない,残念だ」というニュアンスを強く持つ。
