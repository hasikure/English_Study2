文法ポイント

1. -기로 하다(「〜することにする」決定)

  • 意味: 何かをすると決める,決心することを表す。
  • 接続: 動詞の語幹 + 기로 하다。
  • 例文: 시작하다 → 운동을 시작하기로 했어요(運動を始めることにしました) / 가다 → 내일 같이 가기로 했어요(明日一緒に行くことにしました)。
  • 注意: 決定した内容そのものを表すので、過去形 -기로 했다 の形でよく使われる(すでに決定済みというニュアンス)。

2. -(으)면서(「〜しながら」動作の同時進行)

  • 意味: 二つの動作が同時に起きていることを表す。
  • 接続: 動詞の語幹(パッチムなし→면서、あり→으면서)。
  • 例文: 듣다 → 음악을 들으면서 뛰었어요(音楽を聴きながら走りました) / 걷다 → 걸으면서 전화를 받았어요(歩きながら電話を受けました)。
  • 注意: 主語が同じ二つの動作に使う。主語が違う「〜している間に」は -는 동안에 を使う。

3. -는 대신에(「〜する代わりに」代替・交換)

  • 意味: ある行動をせずに、その代わりに別の行動をすることを表す。
  • 接続: 動詞の語幹 + 는 대신에。
  • 例文: 요리하다 → 직접 요리하는 대신에 사 먹었어요(自分で料理する代わりに買って食べました) / 전화하다 → 전화하는 대신에 문자를 보냈어요(電話する代わりにメッセージを送りました)。
  • 注意: 名詞に付くときは 대신에 だけで使う(例: 밥 대신에 빵을 먹었어요= ご飯の代わりにパンを食べました)。

4. -다 보니(까)(「〜し続けていたら,〜していたら(気づいたら)」継続の結果)

  • 意味: ある行動を繰り返し続けた結果、ある状態や発見に至ったことを表す。
  • 接続: 動詞の語幹 + 다 보니(까)。
  • 例文: 하다 → 몇 주를 하다 보니 바지가 헐렁해졌어요(数週間続けていたらズボンがゆるくなりました) / 듣다 → 계속 듣다 보니 익숙해졌어요(聞き続けていたら慣れました)。
  • 注意: 一回の動作の後に気づく -고 보니 と違い、-다 보니 は同じ動作を繰り返し・継続した結果という点がポイント。
