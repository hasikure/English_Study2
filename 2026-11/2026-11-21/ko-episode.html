친구는 커피든지 차든지 아무거나 다 좋다고 했어요.

사실 저는 날씨가 추워지기만 하면 자꾸 따뜻한 차가 생각나요.

그래서 오늘도 결국 따뜻한 차를 한 잔 마셨어요.

文法ポイント

1. -자마자(「〜するとすぐに」直後の動作)

  • 意味: ある動作が起きた直後に、すぐ次の動作や状況が続くことを表す。
  • 接続: 動詞の語幹 + 자마자。
  • 例文: 나가다 → 집을 나가자마자 기분이 좋아졌어요(家を出るとすぐに気分が良くなりました) / 도착하다 → 도착하자마자 전화했어요(着くとすぐに電話しました)。
  • 注意: 前の動作が終わるのとほぼ同時に次が起きるという時間的な近さを強調する。-고 나서 よりも間隔が短い。

2. -(으)려다가(「〜しようとしたが」意図の変更)

  • 意味: 何かをしようと思っていたが、実際にはせずに別のことをした,という意図の変更を表す。
  • 接続: 動詞の語幹(パッチムなし→려다가、あり→으려다가)。
  • 例文: 가다 → 혼자 가려다가 친구랑 같이 갔어요(一人で行こうとしたが友達と一緒に行きました) / 자다 → 일찍 자려다가 드라마를 보느라 늦게 잤어요(早く寝ようとしたがドラマを見ていて遅く寝ました)。
  • 注意: -다가 と似ているが、-(으)려다가 は「〜しようという意図があったが実現しなかった」という点が核心。

3. -든지(「〜でも,〜なり」選択・無差別)

  • 意味: どちらを選んでも構わない,という無差別・選択の意味を表す。
  • 接続: 名詞・動詞の語幹 + 든지(通常二つ以上を並べて使う)。
  • 例文: 커피/차 → 커피든지 차든지 다 좋아요(コーヒーでもお茶でも何でもいいです) / 가다/오다 → 가든지 오든지 마음대로 하세요(行くなり来るなり好きにしてください)。
  • 注意: 話し言葉では -든가 ともよく言う。意味はほぼ同じ。

4. -기만 하면(「〜しさえすれば,〜すると必ず」条件・習慣)

  • 意味: ある条件が満たされると、いつも決まって同じ結果になることを表す。
  • 接続: 動詞・形容詞の語幹 + 기만 하면。
  • 例文: 추워지다 → 날씨가 추워지기만 하면 차가 생각나요(寒くなるといつもお茶を思い出します) / 피곤하다 → 피곤하기만 하면 바로 잠이 들어요(疲れるとすぐ眠ってしまいます)。
  • 注意: 「〜さえすれば」という最小条件のニュアンスと、「そのたびに必ず」という習慣的な結果の両方を含む。
