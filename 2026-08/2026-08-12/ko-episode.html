文法ポイント

1. -(으)니까(理由「〜だから」、後ろに命令・勧誘・意志が続きやすい)

  • 意味: 理由を表す。後ろに命令文・勧誘文・意志表現が続くことが多い。
  • 接続: 動詞・形容詞の語幹がパッチムなし → -니까、あり → -으니까。
  • 例文: 덥다 → 날씨가 더우니까 가벼운 옷을 입으세요(暑いから軽い服を着てください) / 늦다 → 늦었으니까 빨리 가자(遅れたから早く行こう)。
  • 注意: -아/어서(単純な理由・原因)は後ろに命令文・勧誘文を続けられないが、-(으)니까 はそれらを自然に続けられる点が大きな違い。

2. -기로 하다(「〜することにする」決定・約束)

  • 意味: 何かをすることに決めた、約束したという意志を表す。
  • 接続: 動詞の語幹 + 기로 하다。
  • 例文: 가다 → 부산에 가기로 했어요(釜山に行くことにしました) / 만나다 → 다음 주에 만나기로 했어요(来週会うことにしました)。
  • 注意: -(으)ㄹ 것이다(単純な未来の予定)より、「はっきり決定・約束をした」という意志の強さが表れる。

3. -아/어 놓다(「〜しておく」動作の結果を維持)

  • 意味: ある動作をして、その結果の状態をそのままにしておくことを表す。
  • 接続: 動詞の語幹 + 아/어 놓다。
  • 例文: 예매하다 → 기차표를 예매해 놓았어요(電車の切符を予約しておきました) / 열다 → 창문을 열어 놓았어요(窓を開けておきました)。
  • 注意: -아/어 두다 とほぼ同じ意味で置き換え可能だが、-아/어 놓다 のほうが日常会話でより頻繁に使われる。

4. -(으)ㄴ 적이 있다(「〜したことがある」経験)

  • 意味: 過去にある経験をしたことがあるという事実を表す。
  • 接続: 動詞の語幹がパッチムなし → -ㄴ 적이 있다、あり → -은 적이 있다。否定形は「-(으)ㄴ 적이 없다」。
  • 例文: 가다 → 부산에 가 본 적이 있어요(釜山に行ったことがあります) / 먹다 → 이 음식을 먹은 적이 있어요(この料理を食べたことがあります)。
  • 注意: 動詞に -아/어 보다(試しに〜してみる)を挟んだ「-아/어 본 적이 있다」の形もよく使われ、「試しにやってみたことがある」というニュアンスが加わる。
