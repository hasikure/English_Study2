저는 지금 여행 준비를 하는 중이에요.

이번 주말에 비가 올지도 몰라서 우산을 챙겨야지요.

여권도 잊지 말고 꼭 챙겨야지요.

여권 없이 공항에 가면 안 돼요.

日本語訳

私は今、旅行の準備をしている最中です。

今週末は雨が降るかもしれないので、傘を用意しなくちゃ。

パスポートも忘れずに、必ず持っていかなくちゃ。

パスポートなしで空港に行ってはいけません。

文法ポイント

1. -는 중이다(「〜している最中だ」)

  • 意味: 今まさにその動作をしている途中であることを表す。
  • 接続: 動詞の語幹 + 는 중이다。
  • 例文: 하다 → 준비를 하는 중이에요(準備をしている最中です) / 먹다 → 밥을 먹는 중이에요(ご飯を食べている最中です)。
  • 注意: -고 있다(〜している、7/8で学習)とほぼ同じ意味だが、-는 중이다 は「その過程の途中」であることをより強調する。

2. -(으)ㄹ지도 모르다(「〜かもしれない」)

  • 意味: 確信のない推量、可能性を表す。
  • 接続: 動詞・形容詞の語幹がパッチムなし → -ㄹ지도 모르다、あり → -을지도 모르다。
  • 例文: 오다 → 비가 올지도 몰라요(雨が降るかもしれません) / 늦다 → 늦을지도 몰라요(遅れるかもしれません)。
  • 注意: -(으)ㄹ 것 같다(7/10で学習、〜しそう)より確信が低く、「可能性の一つとして」というニュアンス。

3. -아/어야지(「〜しなくちゃ、〜しよう」自分への決意)

  • 意味: 自分自身に対する決意や、そうすべきだという判断を、独り言のように表す。
  • 接続: 動詞の語幹 + 아/어야지(丁寧形は -아/어야지요)。
  • 例文: 챙기다 → 우산을 챙겨야지(傘を持っていかなくちゃ) / 하다 → 공부해야지(勉強しなくちゃ)。
  • 注意: -아/어야 하다(〜しなければならない、7/2で学習)より、独り言・自分への念押しのくだけたニュアンスが強い。

4. -(으)면 안 되다(「〜してはいけない」禁止)

  • 意味: あることをしてはいけない、という禁止・不許可を表す。
  • 接続: 動詞の語幹がパッチムなし → -면 안 되다、あり → -으면 안 되다。
  • 例文: 가다 → 가면 안 돼요(行ってはいけません) / 잊다 → 잊으면 안 돼요(忘れてはいけません)。
  • 注意: -지 마세요(〜しないでください、6/28で学習)は依頼・命令、-(으)면 안 되다 は規則・ルールとしての禁止のニュアンスが強い。
