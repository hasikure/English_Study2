오늘 아침에 갑자기 비가 오는 바람에 버스를 놓쳤어요.

피곤한 데다가 우산도 없어서 정말 힘들었어요.

그런데 저는 그냥 불평만 했어요.

다음부터는 일찍 준비하도록 할게요.

日本語訳

今朝、突然雨が降ったせいで、バスに乗り遅れました。

疲れている上に傘もなかったので、本当に大変でした。

でも私は、ただ文句を言うだけでした。

次からは早く準備するようにします。

文法ポイント

1. -는 바람에(「〜のせいで」予期しない原因)

  • 意味: 予期しない出来事が原因で、望ましくない結果が起きたことを表す。
  • 接続: 動詞の現在連体形(パッチムなし・ありとも -는 바람에)。있다/없다も同じ形。
  • 例文: 오다 → 비가 오는 바람에(雨が降ったせいで) / 놓치다 → 버스를 놓치는 바람에(バスに乗り遅れたせいで)。
  • 注意: -느라고(7/23で学習)は「している最中に」という継続的な原因、-는 바람에 は突発的な出来事による原因。ニュアンスの違いに注意。

2. -(으)ㄴ/는 데다가(「〜な上に、それに加えて」)

  • 意味: 前の状態・事実に、さらに別の要素を付け加える。
  • 接続: 動詞は現在連体形 + 데다가。形容詞はパッチムなし → -ㄴ 데다가、あり → -은 데다가。
  • 例文: 피곤하다 → 피곤한 데다가(疲れている上に) / 비싸다 → 비싼 데다가(高い上に)。
  • 注意: 二つ以上の理由・状況が重なるときに使う。前後の内容が同じ方向(両方否定的、または両方肯定的)だと自然。

3. -기만 하다(「ただ〜するだけだ」)

  • 意味: 他には何もせず、その動作だけをすることを強調する。
  • 接続: 動詞・形容詞の語幹 + 기만 하다。
  • 例文: 불평하다 → 불평만 했어요(文句を言うだけでした) / 웃다 → 웃기만 해요(笑うだけです)。
  • 注意: 「〜만 하다」の形で、他の行動をしなかったという含みが強く出る。

4. -도록 하다(「〜するようにする」)

  • 意味: これからそうするよう意識する、心がける。
  • 接続: 動詞の語幹 + 도록 하다。
  • 例文: 준비하다 → 준비하도록 할게요(準備するようにします) / 늦다 → 늦지 않도록 하다(遅れないようにする)。
  • 注意: 自分への決意にも、相手への指示(-도록 하세요=〜するようにしてください)にも使える便利な形。
